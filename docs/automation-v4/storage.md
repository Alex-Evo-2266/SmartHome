## Реализация

`AutomationStorage` находится в `SmartHome/app/db/repositories/automation_v4/automation_io.py`. V4 хранит определения в YAML-файлах, а не в DB-модели старой системы автоматизаций.

В текущей конфигурации `AUTOMATION_DIR` равен `CONFIG_DIR/automation`, где `CONFIG_DIR` — `BASE_DIR/config_files`; имена файлов имеют вид `{safe_id}.yaml`. Конструктор хранилища создаёт отсутствующие директории.

Реализованные операции:

- `list_ids()` — список идентификаторов имеющихся автоматизаций;
- `load_all(strict=True|False)` — чтение YAML и создание/валидация `AutomationSchema`;
- `save_all(delete_missing=...)` — пакетная запись с возможностью удаления отсутствующих элементов;
- методы чтения/записи отдельной автоматизации, используемые CRUD API.

## Сериализация и сохранность

- Чтение выполняется `yaml.safe_load`.
- Запись выполняется `yaml.dump` с `allow_unicode=True` и `sort_keys=False`.
- Идентификатор преобразуется в безопасное имя файла; `path_for` заменяет `< > : " / \ | ? *` и управляющие символы на `_`, затем обрезает точки/пробелы с краёв. Пустой/полностью очищенный ID вызывает `AutomationIOError`. API применяет более строгое правило и отклоняет ID, если sanitization изменила имя.
- Сохранение выполняется через временный файл с последующим `os.replace`, чтобы замена файла была атомарной в пределах файловой системы.
- Ошибки чтения, YAML-разбора и валидации оборачиваются в `AutomationIOError`.

## Связь с runtime

V4 lifecycle при запуске загружает YAML (`load_all`) и регистрирует схемы в `AutomationManager_V4`. Само сохранение определения не является выполнением автоматизации; обновление runtime manager при CRUD зависит от API/lifecycle wiring.

## Known Issues

- `load_all(strict=False)` и `load_all_with_errors()` доступны, но lifecycle вызывает `load_all()` со строгим поведением по умолчанию. Некорректный YAML может прервать startup.
- YAML не является историей версий: схема содержит `schema_version`, но хранилище этим не предоставляет миграции по версиям.
- Файловое сохранение не означает транзакцию между набором YAML и runtime индексами.
